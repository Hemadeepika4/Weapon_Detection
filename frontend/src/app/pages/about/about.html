Weapon Detection AI

YOLOv12 Security Monitoring System

About the Project

This project is a real-time weapon detection system designed using YOLOv12 and adaptive confidence filtering techniques.

It aims to improve surveillance by detecting weapons in images, videos, and live camera feeds with high accuracy and reliability.

Project Objectives

Accurate Detection

Identify weapons such as guns and knives with high precision.

Real-Time Monitoring

Enable live camera detection for continuous surveillance.

Adaptive Filtering

Reduce false positives using confidence-based filtering.

Threat Classification

Classify results into LOW, MEDIUM, HIGH, VERY HIGH.
